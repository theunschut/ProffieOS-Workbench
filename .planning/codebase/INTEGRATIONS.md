# External Integrations

**Analysis Date:** 2026-07-01

## APIs & External Services

**Hardware Device Communication:**
- **ProffieOS Lightsaber Board** - Custom USB/Bluetooth device
  - Interface: WebUSB (vendor ID 0x1209, product ID 0x6668)
  - Interface: WebBLE (multiple legacy service UUIDs supported)
  - Protocol: UART text-based command/response with `-+=BEGIN_OUTPUT=+-` / `-+=END_OUTPUT=+-` markers
  - Authentication: Optional password via BLE characteristic write

## Data Storage

**Databases:**
- None - Client-side only (no backend database)

**File Storage:**
- Browser LocalStorage only
  - Key: `pwa-sw-enabled` (Service Worker opt-in flag)
  - No persistent data storage to server

**Caching:**
- Browser Cache API (optional Service Worker - disabled by default)
- Service Worker: `wwwroot/service-worker.js` (development - inactive) and `service-worker.published.js` (production)
- Legacy app: `sw.js` caches `app.html` and `Starjedi.ttf`

## Authentication & Identity

**Auth Provider:**
- Custom device-level authentication via ProffieOS board
  - Implementation: BLE password characteristic write (`pwUuid`)
  - Protocol: Plain-text password sent to device, device responds "OK" or error
  - Profiles supported:
    - Service UUID: `713d0000-389c-f637-b1d7-91b361ae7678` with password char: `713d0004-389c-f637-b1d7-91b361ae7678`
    - Multiple legacy BLE service UUIDs also checked (fallback support)

**No user/web authentication** - Application is client-side only, no backend login required

## WebUSB/WebBLE Interop Boundary

### JavaScript Side (`wwwroot/js/*.js`)

**USB Interop (`usb.js`):**
- Exposes: `window.UsbInterop` object with methods
- `requestDevice(filters)` - Prompts user to select USB device
- `connect(dotnetRef)` - Opens device, configures interface 0xFF, sets up read loop
- `reconnect(dotnetRef)` - Reconnects to previously selected device
- `write(bytes)` - Writes to USB endpoint (3 retries, 25ms backoff)
- `stop()` - Stops read loop and closes device
- `selectKnownDevice(index)` - Selects from pre-authorized devices
- `getKnownDevices()` - Lists pre-authorized USB devices
- Callbacks to C#: `_dotnetRef.invokeMethodAsync('OnDataReceived', data)`, `OnDisconnected`
- Internal state: `_device`, `_endpointIn`, `_endpointOut`, `_interfaceNumber`, `_reading` flag

**BLE Interop (`bluetooth.js`):**
- Exposes: `window.BluetoothInterop` object with methods
- `requestDevice(filters)` - Prompts user to select BLE device (with service filters)
- `connect(dotnetRef, profiles)` - Connects GATT, enables RX notifications, sets up handlers
- `reconnect(dotnetRef)` - Reconnects using saved profiles
- `writeChunk(bytes)` - Writes to TX characteristic (3 retries, 20ms backoff)
- `sendPassword(password)` - Writes to password characteristic if present
- `selectKnownDevice(index)` - Selects from pre-authorized devices
- `getKnownDevices()` - Lists pre-authorized BLE devices
- Callbacks to C#: `dotnetRef.invokeMethodAsync('OnDataReceived', data)`, `OnStatusReceived(data)`, `OnDisconnected`
- Fallback logic: If no service filters provided, uses legacy UUIDs
- Internal state: `_device`, `_tx`, `_rx`, `_pw`, `_statusChar`, `_server`

### C# Side (Blazor Services)

**USB/BLE Connection Management (`Services/SaberConnectionService.cs`):**
- Constructor: `SaberConnectionService(IJSRuntime js, SaberCommandService commands)`
- `InitAsync()` - Detects WebUSB/WebBLE availability via `navigator.usb` and `navigator.bluetooth` checks
- `ConnectBleAsync(password?)` - Calls `BluetoothInterop.requestDevice`, then `connect`
- `ConnectKnownBleAsync(index, password?)` - Calls `BluetoothInterop.selectKnownDevice`, then `connect`
- `ConnectUsbAsync()` - Calls `UsbInterop.requestDevice` (hardcoded vendor/product IDs), then `connect`
- `ConnectKnownUsbAsync(index)` - Calls `UsbInterop.selectKnownDevice`, then `connect`
- BLE Profiles: 7 predefined UART service/characteristic UUID combos (ProffieOS proprietary + Nordic UART + others)
- USB Filters: Hardcoded `0x1209:0x6668`
- Event: `StateChanged` (fires on connection state changes)
- Properties: `State`, `ConnectedDeviceName`, `BluetoothAvailable`, `UsbAvailable`

**Command Protocol (`Services/SaberCommandService.cs`):**
- Constructor: `SaberCommandService()`
- Registered as `DotNetObjectReference` and passed to JS interop
- `[JSInvokable] OnDataReceived(string data)` - Called from JS, buffers data until `-+=END_OUTPUT=+-` marker
- `[JSInvokable] OnStatusReceived(string data)` - Called from BLE status characteristic
- `[JSInvokable] OnDisconnected()` - Called from JS on device disconnect
- `SendBytesAsync` - Delegate set by SaberConnectionService to `BluetoothInterop.writeChunk` or `UsbInterop.write`
- Properties: `IsConnected`, `UseTagging`
- Protocol parsing: Looks for `-+=BEGIN_OUTPUT=+-` and `-+=END_OUTPUT=+-` markers, removes carriage returns

**UI Components:**
- `Components/KnownDevicesPanel.razor.cs` - Displays known devices via `UsbInterop.getKnownDevices()` / `BluetoothInterop.getKnownDevices()`
